## 三类问题，三种检查 {intuition}

计算值与实验值之差，至少混着三类来源。它们需要不同的检查，结论也不能互相替代。

| 类别 | 典型来源 | 怎样检查 | 检查通过能说明什么 |
| --- | --- | --- | --- |
| 数值收敛 | 截断能、k 点、自洽与力的阈值、有限差分步长、结构是否弛豫到位 | 逐项加严设置，看**目标量**是否稳定 | 在当前模型下，答案已不依赖这些设置；不说明模型对 |
| 模型准确性 | 交换相关近似、色散校正、PAW 数据集、静态 0 K 晶格、谐近似 | 在同一结构和同一目标量上比较不同方法，或对照更高精度的基准 | 目标量对这些选择有多敏感；不直接给出“哪个对” |
| 实验对应 | 温度与压力、测的是 $d$ 还是 $e$、夹持或自由边界、单晶或多晶或薄膜、取向与畴结构 | 逐项核对实验的定义和条件，让两边比较的是同一个物理量 | 比较本身是否有意义；不说明哪一边更准 |

## 收敛要对目标量检查 {mapping}

::: empirical 总能收敛不等于导数收敛
常见经验是：总能已经稳定时，应力和高阶导数可能还没稳定。平面波基组下的 Pulay 应力是有文档记载的一个具体例子 [@vasp-wiki-pulay]。实际做法是直接对关心的量（弹性常数、玻恩电荷、压电系数）做收敛测试。
:::

::: unverified 待核验
- “导数比总能收敛得慢”作为一般说法需要找到可引用的依据，目前只有 Pulay 应力这一个有文档的例子。
- 有限差分步长存在“太大引入非谐误差、太小放大数值噪声”的权衡；这一点的定量说明需要对照 [@baroni-2001-dfpt] 或具体软件文档。
:::

## 比较方法时固定什么 {mapping}

比较 PBE 与 PBE + D3(BJ) 时，有两种做法，回答的是不同问题：

- 各自优化结构后再算响应：比较的是两套方法的**整体**预测，结构差异和曲率差异混在一起。
- 在同一结构上算响应：把结构差异剔除，只看曲率和耦合项的差异。

两种做法都合理，关键是写清楚固定了什么。结合 [[energy-structure-response]] 的分解（夹持离子项与离子弛豫项、$e$ 与 $d$ 的换算），可以进一步看出差异集中在哪一项。

## 这个框架不能做什么 {mapping}

::: assumption 适用范围
这一节只给出分类和检查方法，不对任何具体材料下“误差主要来自哪里”的结论。那需要具体数据：收敛测试结果、方法比较结果和实验条件。没有这些数据时，三类来源都应保留为待检查的可能性。
:::

## 检验自己 {mapping}

::: question 归类
某次计算的压电系数比实验大一倍。把下面的线索分到三类中，并说出各自下一步该查什么：结构优化时力的阈值较松；实验用的是多晶压片；计算没有考虑温度。
:::
