## 为什么要分层 {intuition}

“计算和实验差得远”这句话里混着性质不同的选择。有些选择改变了**我们在解哪一个方程**，有些只改变**这个方程解得有多准**。不先分开，很容易把“换泛函”和“加截断能”当成同一类调整，也很难说清一次改动究竟排除了什么。

一个实用的判别方法：设想把某个设置推到极限（基组无限大、k 点无限密、收敛判据无限严），答案会不会趋于同一个数？会的话，这个设置属于表示或数值求解层；不会的话，它属于理论近似或物理模型层。

::: approximation 判别方法本身也是近似的
这个判别对大多数设置成立，但有边界情况。例如 PAW 的冻芯处理：增加平面波截断能并不会让冻芯近似消失，它更像理论近似，却又是“表示”方案的一部分。分层是思考工具，不是严格的术语分类。
:::

## 四个层次 {intuition}

| 层次 | 回答的问题 | 本例中的选择 |
| --- | --- | --- |
| 物理模型 | 哪些自由度和条件进入问题？ | 周期性完整晶体，原子核视为经典静止点（玻恩–奥本海默近似），温度为 0 K，不含零点振动 |
| 理论近似 | 用什么理论描述这些自由度？ | Kohn–Sham DFT，交换相关用 PBE，再加 D3(BJ) 色散校正 |
| 表示 | 用什么基和数据表示波函数、密度？ | 平面波基组 + PAW 数据集（决定哪些电子作为价电子） |
| 数值求解 | 怎样把方程离散并求解到足够精度？ | 截断能、k 点网格、自洽与力的收敛阈值、结构弛豫、有限差分步长或微扰求解 |

## PBE、D3(BJ)、PAW 各在哪一层 {mapping}

::: definition PBE
一种广义梯度近似（GGA）：把交换相关能写成电子密度及其梯度的函数 [@pbe-1996]。它规定了“解的是哪一个 Kohn–Sham 问题”。无论基组和 k 点多充分，得到的都是 PBE 的答案，而不是精确泛函的答案。
:::

::: definition D3(BJ)
在 DFT 总能上另加的色散能修正：由原子对（以及可选的三体）项组成，系数和阻尼参数事先确定 [@grimme-2010-d3]。BJ 指 Becke–Johnson 形式的短程阻尼函数 [@grimme-2011-bj]。它同样属于理论近似层，不随基组收敛。
:::

::: definition PAW
投影缀加波方法：把全电子波函数写成平滑的赝波函数加上原子球内的局域修正，使平面波基组可以用较低的截断能描述价电子 [@bloechl-1994-paw]。VASP 中的实现与超软赝势有形式上的对应 [@kresse-1999-paw]。它主要属于表示层。
:::

::: unverified 待核验
- PAW 数据集的选择（芯区划分、是否用 `_h` 或 `_GW` 版本）在多大程度上算“表示”、多大程度上算“近似”，需对照 [@kresse-1999-paw] 关于冻芯近似的讨论写准。
- VASP 中 `IVDW` 取值与 D3、D3(BJ) 的对应关系，需按当前版本的 [@vasp-wiki-ivdw] 核对后再写进正文。
- D3(BJ) 对有机晶体晶格参数和弹性性质的影响有多大，应引用基准研究，不能凭印象写。
:::

## 分层对判断误差的用处 {mapping}

分层后，“计算与实验不符”可以拆成三个能分别回答的问题：

1. 在当前表示下，数值是否收敛？这可以通过加大计算量自行检查。
2. 当前理论近似对**这个目标量**是否足够？这只能靠换方法比较，或对照更高精度的基准。
3. 物理模型与实验条件是否一致？例如静态 0 K 晶格对比室温样品。

第三点和误差分类的细节放在 [[error-sources]]。这里要记住的是：同一套设置对不同目标量的可靠程度可能不同。结构参数主要取决于能量曲面的极小点位置，压电响应还取决于曲面的曲率和耦合项，见 [[energy-structure-response]]。

- 把 PBE 换成另一种泛函
- 关掉 D3(BJ)
- 把 k 点网格加密
- 从静态晶格改为考虑有限温度下的平均
