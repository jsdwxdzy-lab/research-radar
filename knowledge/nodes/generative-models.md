## 直觉 {intuition}

生成模型要解决的问题是：给定一堆样本（分子、晶体结构、图像），学出一个分布 $\hat p(x)$，使得从它里面采出来的新样本“像”训练数据，但又不是训练数据的拷贝。

两条完全不同的路线：

- **一次性生成**：从噪声出发，经过固定的若干步变换，一次得到整个样本。扩散模型、流匹配都属于这一类。样本的每个部分同时决定，没有先后顺序。
- **逐段生成**：按某种顺序一个接一个地决定样本的各个部分（一个原子一个原子、一个 token 一个 token）。自回归模型属于这一类。

两者的差别在**结构**上：一次性生成必须自己保证各部分之间的一致性；自回归天然保证一致性，但要选定一个顺序，而顺序本身会引入偏差（例如晶体里没有天然的“第一个原子”）。

图里画了一次性生成的骨架：数据分布经过一条固定的“加噪”路径被抹成噪声，模型学的就是这条路径的**逆过程**；采样时从噪声出发沿逆路径走回去。

## 定义与公式 {math}

### 扩散模型：学加噪的逆过程

DDPM [@ho-2020-ddpm] 定义一条固定的前向马尔可夫链，每一步加一点高斯噪声：

$$q(x_t \mid x_{t-1}) = \mathcal{N}\!\left(x_t;\ \sqrt{1-\beta_t}\,x_{t-1},\ \beta_t \mathbf{I}\right)$$

其中 $\beta_t$ 是第 $t$ 步的噪声方差（预先设定的调度表）；$\sqrt{1-\beta_t}$ 保证方差大致守恒；$\mathbf{I}$ 是单位矩阵。多步合并后有闭式：

$$q(x_t \mid x_0) = \mathcal{N}\!\left(x_t;\ \sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)\mathbf{I}\right), \qquad \bar\alpha_t = \prod_{s=1}^{t}(1-\beta_s)$$

其中 $\bar\alpha_t$ 是累积保留系数。

反向过程用网络 $\epsilon_\theta$ 预测每一步加的噪声：

$$\mathcal{L} = \mathbb{E}_{t,\,x_0,\,\epsilon}\left[\left\|\epsilon - \epsilon_\theta\!\left(\sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon,\ t\right)\right\|^2\right]$$

其中 $\epsilon$ 是实际加的噪声；$\epsilon_\theta(\cdot,t)$ 是以噪声水平和当前样本为输入的预测网络。这个目标就是从变分下界化简出来的版本 [@ho-2020-ddpm]。

### 得分 SDE：把扩散写成连续时间

得分 SDE 框架 [@song-2020-score-sde] 把上面的离散链写成随机微分方程：

$$dx = f(x,t)\,dt + g(t)\,dw$$

其中 $f$ 是漂移项；$g$ 是扩散系数；$dw$ 是维纳过程增量。对应的反向时间 SDE 是

$$dx = \left[f(x,t) - g(t)^2 \nabla_x \log p_t(x)\right]dt + g(t)\,d\bar w$$

其中 $\nabla_x \log p_t(x)$ 是**得分函数**（对数概率密度的梯度）；$d\bar w$ 是反向时间的维纳过程。模型只需要学得分函数，而不需要知道 $p_t$ 本身——这是这一类方法的核心技巧。

::: theorem 得分与去噪的等价
在高斯加噪下，最优去噪器与得分函数有精确关系：$\nabla_x \log p_t(x) = -\mathbb{E}[\epsilon \mid x_t = x]/\sqrt{1-\bar\alpha_t}$。所以“预测噪声”和“估计得分”是同一件事的两种说法 [@song-2020-score-sde]。
:::

### 流匹配：学一个速度场

流匹配 [@lipman-2022-flow] 不用加噪-去噪的语言，而是直接学一个把噪声搬到数据的**速度场**：

$$\mathcal{L} = \mathbb{E}_{t,\,x_0,\,x_1}\left[\left\|v_\theta(x_t, t) - (x_1 - x_0)\right\|^2\right], \qquad x_t = (1-t)\,x_0 + t\,x_1$$

其中 $x_0$ 是噪声样本；$x_1$ 是数据样本；$x_t$ 是二者之间的直线插值；$v_\theta$ 是待学的速度场。这个目标不需要模拟 SDE，训练更直接。

::: approximation 三者的关系
扩散、得分 SDE、流匹配在数学上是同一族方法的三种参数化：都是学一个从简单分布到数据分布的变换场，区别在于路径的形状（加噪路径 vs 直线插值）与训练目标的推导方式。采样时的步数、离散化误差、以及能否用更少的步数得到好样本，是三者在实践中真正的差别。
:::

## 在本研究线里的样子 {mapping}

### 在结构生成里要额外处理什么

分子和晶体不是普通向量，生成时还要满足：

- **原子种类与数目的离散性**：类别变量不能直接加高斯噪声，需要用 one-hot 的连续松弛或在离散空间定义过程；
- **几何对称性**：整体平移、旋转、以及同类原子的置换不改变结构（见 [[equivariance]]）；好的模型把这些对称性内建进去，而不是靠数据去学；
- **周期性**：晶体要在晶胞、分数坐标上生成，边界条件与真空中的分子完全不同（见 [[crystal-generative-models]]）。

### 评价指标：生成得像不像

不能只看单个样本“顺眼”，要有分布层面的指标。分子生成里常用：

- **有效性/唯一性/新颖性** (validity / uniqueness / novelty)：生成的分子能不能通过化学规则检查、彼此是否重复、是否在训练集里出现过 [@polykovskiy-2020-moses]；
- **Fréchet ChemNet Distance (FCD)**：把生成集与参考集分别送进一个固定的化学信息网络，比较两组特征分布的 Fréchet 距离 [@preuer-2018-fcd]。

::: unverified 待核验
- FCD 依赖固定的参考网络与参考集，跨数据集比较没有绝对尺度；把它当“越小越好”的相对指标，不要跨体系比较数值。
- 上述指标是为**分子**（图）设计的。晶体结构的对应指标（晶胞相似度、堆积相似度、能量排序一致性）还在演化，没有公认标准；参见 [[structure-similarity]]，但具体做法需要按文献核对。
- 触发本条目的 11 篇论文的具体方法与结果尚未精读，正文只给一般框架，不引用其报告的数字。
:::

## 常见坑 {mapping}

- **把一次性生成当成“更先进”**：一次性和自回归各有适用场景。晶体里原子等价、没有自然顺序，自回归要先定义一个顺序，这个选择会引入系统性偏差。
- **只看单样本质量**：几个漂亮样本不能说明分布学到了；必须用分布层面的指标，并且和参考集放在一起看。
- **忽略对称性**：不内建对称性的模型会把同一结构的不同旋转当成不同样本，训练效率低，还会生成重复结构。
- **拿指标当物理正确性**：FCD 低只说明“像训练数据”，不说明生成的结构能量合理。结构生成之后仍要做能量排序与弛豫（见 [[csp-search-ranking]]）。
- **训练集泄漏进评价**：新颖性指标必须在训练集之外计算，否则数字没有意义。
